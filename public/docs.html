Dokumentasi REST API Aurora Aset

Spesifikasi OpenAPI 3.0 untuk integrasi pihak ketiga, skrip, dan otomasi manajemen aset.

Unduh OpenAPI JSON
Header Autentikasi (Bearer Token)

Seluruh endpoint operasional (kecuali login) memerlukan header otorisasi JWT: 

Authorization: Bearer <TOKEN_HASIL_LOGIN>

Lakukan request POST ke /api/auth/login dengan payload {"username":"admin","password":"Admin@12345"} untuk mendapatkan token.
